


Kani nga Java program naggamit og tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort. Ang goal ani kay ang arrange sa mga numbers gikan sa pinakagamay hangtod sa pinakadako. Ang Bubble Sort magkumpara sa duha ka nagtapad nga numbers ug magbaylo sa ilang pwesto kung kinahanglan. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang ni sa sakto nga pwesto. Samtang ang Insertion Sort magkuha og number ug ibutang niyasa sakto nga pwesto sa mga numero nga arrange na. Lahi-lahi ilang pamaagi bisag parehas ang ilang goal nga mahan-ay ang mga numero.


Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay magkumpara ra kini sa duha ka magtapad nga number. Kung daan nang arrange ang mga numbers, mas maayo ang Insertion Sort kay dili na kinahanglan ibalhin ang mga number ug mas paspas makahuman. Kung modaghan ang mga number sa array, modaghan sad ang trabaho sa kada algorithm ug  mas dugay ang pag-sort. Importante nga makabalo ta sa lain-laing sorting algorithms aron makapili ta sa angay nga pamaagi depende sa problema ug mahimong mas maayo ug epektibo nga programmer.
